# Diabetes Health Indicator Dataset — Data Documentation

---

## Dataset Overview
This project uses the **Diabetes Health Indicator Dataset**, a synthetically generated population-level health dataset designed to model known risk factors associated with diabetes diagnosis.

The dataset integrates demographic, lifestyle, medical history, and clinical variables while preserving privacy and avoiding identifiable patient information.

---

## Source
- **Platform:** Kaggle  
- **Authors:** Rakesh Kolipaka, Ranjith Kumar Digutla  
- **Year:** 2025  

The dataset was generated using statistical distributions informed by public health and clinical research sources, including the CDC, WHO, and International Diabetes Federation.

---

## Dataset Characteristics
- **Observations:** ~100,000
- **Variables:** 31
- **Outcome Variable:** Binary diabetes diagnosis  
  - `0` = No diabetes diagnosis  
  - `1` = Diagnosed with diabetes

Initial inspection shows:
- no missing values
- no duplicate rows
- approximately 60/40 class split

---

## Variable Groups

### Outcome Variable
- Binary indicator of diabetes diagnosis

### Demographic and Socioeconomic Variables
- Age
- Gender
- Ethnicity
- Education level
- Income level
- Employment status

### Lifestyle and Behavioral Variables
- Smoking status
- Alcohol consumption (weekly)
- Physical activity (minutes per week)
- Sleep duration
- Screen time
- Diet quality score

### Medical History Indicators
- Family history of diabetes
- Hypertension history
- Cardiovascular history

### Clinical and Physiological Measurements
- BMI
- Waist-to-hip ratio
- Blood pressure (systolic, diastolic)
- Heart rate
- Lipid profile (total cholesterol, HDL, LDL, triglycerides)
- Glycemic markers (fasting glucose, postprandial glucose, insulin, HbA1c)

### Derived Risk Measures
- Diabetes risk score
- Diabetes stage (categorical severity indicator)

## Data Organization

### `data/raw/`
Contains the original dataset exactly as obtained from the source.

- Files in this directory are **tracked in version control**
- These files should never be modified directly
- They represent the source of truth for all analyses

### `data/processed/`
Contains processed datasets generated by the preprocessing pipeline.

- Files in this directory are **not tracked** in version control
- Contents are generated by running the preprocessing steps in:
  - `notebooks/final_project.ipynb`
- This ensures that processed data is fully reproducible

---

## Data Usage Notes
- Although the data is synthetic, values fall within medically realistic ranges.
- Conclusions should be interpreted as methodological demonstrations rather than clinical recommendations.
- Any inconsistencies between dataset documentation and the CSV are resolved by treating the CSV as authoritative.

---

## Reproducibility
To regenerate processed data:
1. Place raw dataset(s) in `data/raw/`
2. Run the preprocessing section of `notebooks/final_project.ipynb`
3. Processed outputs will be written to `data/processed/`

No manual data manipulation is required.
